# Fontes do aplicativo

As fontes são empacotadas no aplicativo e não dependem de acesso à rede em
tempo de execução.

## Google Sans

- origem: release oficial `v14.000` de
  `https://github.com/googlefonts/googlesans`;
- arquivo da release:
  `build/GoogleSans/android/variable/GoogleSans[GRAD,opsz,wght].ttf`;
- arquivo local: `google_sans/GoogleSans-Variable.ttf`;
- SHA-256:
  `7dd96f5c236defe6e611530762c03e1e2c22e74a83dba92d89269b0b129a699c`;
- licença: SIL Open Font License 1.1, em `google_sans/OFL.txt`.
